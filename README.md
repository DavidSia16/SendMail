# SendMail

Aplicação web em PHP para o envio de e-mails de forma automatizada e prática.

## Sobre o Projeto

O SendMail foi desenvolvido para facilitar o disparo de mensagens eletrônicas através da integração com servidores SMTP. A aplicação conta com uma interface simples para preenchimento de destinatário, assunto e mensagem.

## Funcionalidades

* Interface intuitiva para composição de e-mails.
* Integração com biblioteca de envio de mensagens (PHPMailer).
* Configuração de credenciais de servidor SMTP.

## Tecnologias Utilizadas

* PHP
* HTML / CSS
* PHPMailer

## Como Executar

1. Certifique-se de ter um ambiente de servidor local configurado com suporte a PHP (como XAMPP, WampServer ou Docker).
2. Clone este repositório ou faça o download dos arquivos no diretório raiz do seu servidor web (ex: `htdocs` ou `www`).
3. Configure as credenciais do seu servidor de e-mail (SMTP) no arquivo de configuração correspondente.
4. Acesse o projeto através do seu navegador no endereço local correspondente (ex: `http://localhost/SendMail/`).
